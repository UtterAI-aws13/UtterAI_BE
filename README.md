# UtterAI_BE

UtterAI backend repository.

현재 저장소는 기능 백엔드 설계 문서와 협업 규칙을 우선 관리한다.

## Current Scope

- 기능 백엔드 아키텍처 문서 관리
- 이슈/PR 템플릿 관리
- 이후 FastAPI 기반 백엔드 구현 반영

## Main Document

- `utterai_functional_backend_architecture.md`

## Branch Strategy

- `dev`: 기본 개발 브랜치
- 기능 작업은 `feature/*`
- 버그 수정은 `fix/*`
- 문서 작업은 `docs/*`

상세 규칙은 `CONTRIBUTING.md`를 따른다.
